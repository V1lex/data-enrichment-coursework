# Дополнительные отзывы: независимая разметка

Источник: [Women's E-Commerce Clothing Reviews](https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews), публикация nicapotato на Kaggle. На странице указана лицензия [CC0: Public Domain](https://creativecommons.org/publicdomain/zero/1.0/). Выбран предусмотренный codebook альтернативный источник. Данные относятся к обезличенному коммерческому источнику; конкретный магазин автором не раскрывается.

| Файл | Назначение | Объём |
| --- | --- | --- |
| pilot.json | Проверка инструкции | 20 |
| main.json | Основная независимая разметка | 120 |
| reserve.json | Резерв при исключении примеров | 20 |

CSV содержат те же тексты. Рейтинги и исходные рекомендации исключены из файлов разметки. Классы не зашифрованы в идентификаторах или порядке строк. Источники записаны в sources.csv. Предварительный отбор по рейтингам не гарантирует баланс человеческих меток.

## Протокол

1. Создать два отдельных проекта Label Studio: A1 и A2. Установить интерфейс из label_studio.xml и импортировать в каждый один и тот же pilot.json.
2. Каждый участник независимо размечает все 20 текстов по codebook, записывает время в секундах и комментарии. Метки: positive = 1, negative = 0, disputed = спорный.
3. Сохранить независимые экспорты до обсуждения, разобрать расхождения и уточнить codebook.
4. Импортировать main.json в два проекта для основной разметки. Каждый размечает все 120 текстов, не просматривая ответы другого.
5. Сохранить оба экспорта. Согласованность вычислять до согласования ответов. Итоговые метки хранить отдельно. При нехватке 50 положительных или 50 отрицательных примеров использовать резерв; метки ради баланса не изменять.

Пилотные примеры отделены от основной партии. Для ближайшей сдачи 20 пилотных текстов сами по себе не закрывают требование 50 объектов с двумя аннотаторами: необходима также основная разметка.

## Ограничения

Отобраны полные тексты длиной 5–80 слов. Исключены нормализованные повторы, совпадения и вхождения текстов исходного UCI. Проверка не исключает смысловые перефразирования. Тексты сохранены без перевода и генерации. Корпус относится к одежде: это изменение тематики относительно товаров, ресторанов и фильмов UCI; предварительный отбор по крайним рейтингам также влияет на состав выборки.
