# Итоговые рамки

`annotations_A1.json` и `annotations_A2.json` - исходные экспорты, `annotations_final.json` - 100 итоговых рамок класса `pet_head`.

При IoU > 0,9 усредняются координаты сторон A1 и A2; при IoU ≤ 0,9 выбирается A1. Это автоматический выбор без дополнительной проверки правильности. Метод и неокруглённый IoU указаны в каждой записи.

`bbox_percent_xyxy` содержит границы в процентах от ширины и высоты изображения, начало координат - слева сверху. `image_width`, `image_height`, `id` и `image_filename` связывают разметку с исходным изображением.
