# Итоговые рамки голов животных

`annotations_final.json` содержит по одной итоговой рамке `pet_head` для каждого из 100 изображений. Исходные экспорты разметки сохранены в `annotations_A1.json` и `annotations_A2.json`.

Для каждой пары независимо размеченных рамок сначала вычислен IoU. При IoU строго больше 0,9 координаты каждой из четырёх сторон усреднены; при IoU меньше или равном 0,9 выбрана рамка A1. Значение ровно 0,9 в текущих данных не встречается. Метод выбора и исходное значение IoU записаны в каждой строке; IoU не округляется до применения порога.

`bbox_percent_xyxy` содержит `x_min`, `y_min`, `x_max`, `y_max` в процентах от размеров исходного изображения, с началом координат в левом верхнем углу. `image_width` и `image_height` — исходные размеры в пикселях. Идентификатор `id` и `image_filename` связывают рамку с JPG в ручном наборе Drive. При вычислении допущена погрешность чисел с плавающей запятой на границе изображения не более 1e-10 процентного пункта; итоговые координаты ограничены диапазоном от 0 до 100.

Файл представляет результат автоматического правила, а не дополнительное ручное согласование. Низкий IoU не меняет выбор A1; правильность такой рамки отдельно не подтверждена.
