# Изображения: разбиение и отражение

`oxford_pet_split_seed42.csv` фиксирует разбиение 3 670 пригодных исходных изображений Oxford Pet `trainval`: 2 936 в train и 734 в validation. Разбиение выполнено до аугментации по породе с seed 42; алгоритм, хеши и состав приведены в `oxford_pet_split_seed42.json`. Официальные изображения Oxford Pet из `test` в это разбиение не включены: готовых XML-рамок для них в рабочем наборе нет.

Для каждого изображения создана горизонтальная копия в `.local-data/augmented/images/oxford_pet_horizontal_flip/`. Копии сохраняют часть исходного изображения: в train находятся 2 936 копий, в validation — 734. Для обучения использовать оригиналы train и их отражения; для оценки — только оригиналы validation. Копии validation хранятся по просьбе пользователя, но помечены как непригодные для обучения и оценки. Так исходное изображение и его отражение не распределяются между разными частями.

Для каждой из 100 самостоятельно добавленных фотографий создана копия в `.local-data/augmented/images/manual_horizontal_flip/`; все оригиналы и копии этого дополнительного набора предназначены для train. Разметка скопирована из `annotation/images/annotations_final.json` с пересчётом горизонтальных координат. Файл `annotations.json` в каждой папке содержит рамки, размеры, связь с оригиналом, назначение и хеши; у дополнительных фотографий также сохранены автор и ссылка на лицензию.

В Oxford Pet исходные рамки трактуются как Pascal VOC в пикселях: координаты XML — с единицы, обе границы включены. В итоговом JSON используются координаты `xyxy` с нуля, правая и нижняя границы не включены: после отражения `x_min = width − xmax_xml`, `x_max = width − xmin_xml + 1`, `y_min = ymin_xml − 1`, `y_max = ymax_xml`. У двух исходных JPG EXIF Orientation равен 0 (неопределён); они обработаны в исходной ориентации пикселей, как в исходном манифесте. Для ручного набора рамки хранятся в процентах; формулы указаны в его README.

PNG-копии сохраняют пиксели без повторного сжатия JPEG. Это геометрическая аугментация, а не генерация новых изображений моделью. `.local-data` исключена из Git: сами изображения и JSON с рамками нужно отдельно сохранить или перенести на Drive. Для Oxford Pet сохраняйте сведения о происхождении и лицензии источника, для добавленных фотографий — соответствующие авторство и лицензии из манифеста.
