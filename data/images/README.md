# Разбиение и отражение изображений

`oxford_pet_split_seed42.csv` фиксирует 3 670 пригодных изображений Oxford Pet trainval: 2 936 train и 734 validation. Алгоритм и хеши указаны в JSON рядом. В ноутбуке обучения validation дополнительно делится пополам на validation и test; для оценки используются только оригиналы.

Горизонтальные копии Oxford и 100 ручных изображений вместе с `annotations.json` находятся в архиве `augmented/images/augmented_images.zip` на Drive. Для обучения разрешены только отражения исходного train и ручных примеров. Копии evaluation-изображений не используются, что исключает попадание пары оригинал-отражение в разные части эксперимента.

Oxford XML преобразуется из Pascal VOC с координатами от 1 в `xyxy` от 0 с исключёнными правой и нижней границами. Рамки ручных изображений заданы в процентах. Отражение является геометрической аугментацией, а не генерацией ИИ; метаданные источников и лицензии сохранены вместе с данными.
