# Синтетические отзывы

`draft_codex.json` содержит 3 000 синтетических отзывов, написанных Codex с опорой на примеры из train разбиения `../uci_split_seed42.csv`. Это сгенерированные тексты, а не реальные отзывы. Поле `source` обозначает тематику UCI (товары Amazon, фильмы IMDb, рестораны Yelp), а не фактическое происхождение текста. Метки заданы при создании: 0 — negative, 1 — positive; в каждой из шести комбинаций тематики и метки по 500 записей.

При подготовке использовались отдельные примеры из train, а не сопоставление каждого результата с исходным отзывом; идентификаторы конкретных примеров в файле не сохранены. Общее разбиение зафиксировано до генерации. Набор предназначен только для обогащения обучающих данных, не для проверки модели.

Проверены число и уникальность ID и нормализованных текстов, баланс классов и отсутствие точных нормализованных совпадений с очищенным UCI. Внутри набора проверены и переработаны пары с посимвольным сходством не менее 0,82; этот порог не выявляет все смысловые повторы.

**Ограничения:** независимая проверка меток и смыслового разнообразия не проводилась. В наборе заметно повторяются ситуации и парные положительные и отрицательные формулировки. Такой состав может облегчить классификацию искусственным образом и исказить сравнение методов; перед использованием в эксперименте необходимо провести аудит разнообразия и меток и при необходимости переработать данные. Имя файла `draft_codex.json` сохранено, поскольку качество набора ещё не подтверждено.
