# Черновик синтетических отзывов

`draft_codex.json` содержит 300 из запрошенных 3 000 отзывов, написанных Codex по образцу текстов из train разбиения `../uci_split_seed42.csv`. Это синтетические тексты, а не реальные отзывы. Значение `source` обозначает тематику UCI (товары Amazon, фильмы IMDb, рестораны Yelp), а не фактическое происхождение текста. Метки заданы при создании: 0 — negative, 1 — positive; в каждой из шести комбинаций тематики и метки по 50 записей.

Проверены уникальность ID и нормализованных текстов, отсутствие точных нормализованных совпадений с очищенным UCI и пары внутри черновика с посимвольным сходством не менее 0,82. Независимая проверка правильности меток и смысловых повторов не проводилась. Черновик не является завершённым набором и пока не предназначен для окончательных выводов эксперимента.
