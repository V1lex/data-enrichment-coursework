# Синтетические отзывы

`draft_codex.json` содержит 3 000 искусственных отзывов, созданных по примерам обучающей части UCI: по 500 для каждой пары тематики Amazon, IMDb или Yelp и метки 0 или 1. Конкретный исходный пример для каждой записи не сохранён.

Набор предназначен только для train. Проверены ID, баланс и точные совпадения с UCI; похожие тексты переработаны. Независимой проверки меток и разнообразия не было, повторяющиеся ситуации могут влиять на результаты эксперимента.
