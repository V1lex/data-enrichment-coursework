# Разбиение отзывов UCI

`uci_split_seed42.csv` фиксирует разбиение 2 979 записей из `processed/text/reviews_clean.csv` на train (2 381), validation (299) и test (299). Файл содержит идентификаторы, источники, исходные метки и назначенную часть. Исходная очищенная таблица находится в архиве данных проекта на Google Drive; её SHA-256 и точный алгоритм разбиения записаны в `uci_split_seed42.json`.

Разбиение стратифицировано по источнику и метке. Для создания синтетических примеров разрешено использовать только train; validation и test предназначены для оценки. Проверка точных нормализованных совпадений между частями пройдена, но она не исключает смысловые повторы.
