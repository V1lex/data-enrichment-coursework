# Разбиение UCI

`uci_split_seed42.csv` фиксирует 2 979 очищенных отзывов: 2 381 train, 299 validation и 299 test. Разбиение стратифицировано по источнику и метке; алгоритм и хеши записаны в `uci_split_seed42.json`. Очищенные данные хранятся на Drive.

Для генерации и обучения используют только train. Точные нормализованные совпадения между частями проверены; смысловые повторы могут сохраняться.
